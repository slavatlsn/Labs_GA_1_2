# ЛР1 и ЛР2 — Эволюционное программирование и генетические алгоритмы

Группа **517**, номер в списке **24**, год **2026**. Индекс группы Q=1.
Вариант: `1 + ((17*24 + 7*1 + 26) % 20) = 2`.

- **ЛР1:** минимизация функции Розенброка, 7 координат, каждая в [-5, 10].
- **ЛР2:** рюкзак с конфликтующими предметами; 40 предметов, 72 конфликтные пары, емкость 267.

Ключевые алгоритмы реализованы чистым python кодом. Готовые оптимизаторы и пакеты генетических алгоритмов не используются.
NumPy нужен для массивов и RNG, Matplotlib — для графиков.

## Готовые результаты

## Установка

Эксперимен проведен на **Python 3.12.14**, NumPy 2.3.5, Matplotlib 3.10.8. Для точного повторения рекомендуются Python 3.12 и `requirements.txt`.

Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

`requirements.txt` содержит общие минимальные зависимости; установка по нему допускает другие версии и не гарантирует побитовое совпадение случайных последовательностей и чисел.

## Запуск

Из корня проекта:

```bash
python -m unittest discover -s tests -v
python -m evolabs.runner --lab 1
python -m evolabs.runner --lab 2
python -m evolabs.analyze
python -m evolabs.verify
```

Поставленные результаты уже заполнены. runner пропускает завершенные задания; если процесс оборвался, незавершенные запускаются сначала с тем же seed. История записывается перед финальным `result.json`. При изменении поискового кода, конфигурации или данных прежний каталог не используется: будет явная ошибка.

Чтобы выполнить **новую серию**, сохранив приложенную:

```bash
python -m evolabs.runner --lab 1 --output results/repeat_lab1
python -m evolabs.runner --lab 2 --output results/repeat_lab2
```

Один отдельный запуск можно повторить с короткой конфигурацией, сохранив её структуру и единственный seed:

```bash
python -m evolabs.runner --lab 1 --config configs/my_lab1.json --output results/my_lab1
```

## Алгоритмы

### ЛР1

Вещественный ГА: популяция 100, турнир 3, элитизм 2, BLX-alpha с alpha=0.25 и вероятностью 0.9, гауссовская мутация каждой координаты с вероятностью 1/7, многократное отражение в границы. Сравнение `sigma=0.015` и `sigma=0.06` меняет только один фактор. Sigma задаёт долю ширины интервала (15), абсолютные стандартные отклонения 0.225 и 0.9. Baseline — 30 000 равномерных точек. Seed 1000–1019.

### ЛР2

Бинарный ГА: популяция 100, турнир 3, элитизм 2, равномерный кроссовер с вероятностью 0.9, начальная вероятность единицы 0.2. Сравнения:

- `penalty_bit` / `repair_bit`: штраф против ремонта при одинаковой bit-flip мутации;
- `penalty_bit` / `penalty_swap`: bit-flip против обмена двух позиций при одинаковом штрафе;
- `random_feasible`: случайная перестановка предметов и последовательное допустимое включение, 12 000 наборов.

Bit-flip инвертирует каждый бит с вероятностью 1/40. Swap меняет две различные позиции каждого потомка; число единиц сохраняется только этой мутацией. Ремонт удаляет худший по value/weight конец конфликтной пары, затем предметы с низким value/weight до допустимого веса; не добавляет предметы. Штраф минимизирует `-value + (1+sum(values))*(excess_weight + conflict_count)`.

Seed поиска 2000–2019, генерации данных 51724. Первичная цель, нарушения и штраф различаются; отчёт сравнивает ценность только допустимых итоговых решений. Точный решатель `evolabs/exact.py` использует собственный branch-and-bound с дробной верхней границей. Он запускается анализатором после ГА и не передаёт ответ в поиск.

## Архитектура

- `evolabs/problems.py`: исходные задачи, отражение, ограничения, ремонт, генератор данных.
- `evolabs/search.py`: собственные операторы, единый учёт бюджета, цикл поиска.
- `evolabs/runner.py`: конфигурации, seed, сохранение, возобновление между запусками.
- `evolabs/exact.py`: независимый точный ориентир для ЛР2.
- `evolabs/analyze.py`: статистики, сводные CSV/JSON и графики.
- `evolabs/verify.py`: независимая проверка всех решений и воспроизведение выбранных запусков.
